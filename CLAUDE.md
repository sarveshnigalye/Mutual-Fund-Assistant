# Milestone2 Project Guidelines

- **Python Environment**: Use `.venv\Scripts\python.exe` (or `python`).
- **Virtual Environment Path**: `f:\AI projects\Milestone2\.venv\Scripts\python.exe`
- **Dependencies**: All packages including `streamlit`, `chromadb`, `scikit-learn`, `pandas` are installed in `.venv`.
- **Testing**: Run tests with `.venv\Scripts\python.exe -m pytest tests/` or `python -m pytest tests/`.
